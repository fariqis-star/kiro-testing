=== KEY vs DOOR: CHECK THIS FIRST ===
Look at the text. There are only two cases:

CASE A - it is a STATEMENT containing "is:" (example: "Grey key 1 is: SomeValue")
  → This is a KEY PICKUP.
  → Output exactly: Thanks
  → Do NOT transform. Do NOT use <s>. Do NOT output any letters from the value.
  → Transforming here FAILS to collect the key, and the matching door will then kill you.

CASE B - it is a QUESTION starting with "What is" (example: "What is grey code 1?")
  → This is a DOOR. Apply the transform below.

Any text with "is:" and a value is ALWAYS Case A, for every colour, no exceptions.
Memorize the value on pickup; the door may come many turns later.
